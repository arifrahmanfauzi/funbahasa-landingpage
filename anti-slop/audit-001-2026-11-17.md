## Extra fixes found during verification

- Duplicate Alpine `v2.x.x` script removed from 11 pages (`artikel.html`, `cerpen.html`, `cerita-anak.html`, `esai.html`, `baca_karya.html`, `karya-detail.html`, and all five `kategori-*.html` pages). They had loaded Alpine twice.
- Broken script blocks on `artikel.html`, `cerpen.html`, `cerita-anak.html`, `esai.html`: a stale `<script>` was left unclosed and a stray `]` sat before `function load*()`, so all four pages threw `SyntaxError` and `loadArtikel` / `loadCerpen` / `loadCeritaAnak` / `loadEsai` were undefined. Fixed; all four now load with zero console errors.

## Verification results

- All 10 sampled active pages: zero dead anchors (`#`, `javascript:`, empty), zero stale no-op classes, all local `.html` link targets return 200, Nunito (`font-title`) renders on headings, zero JS console errors (except one pre-existing 404 for `img/default-avatar.svg` on `profil-pengguna.html`, which has a working inline `onerror` fallback).
- Contrast measured after fixes: white on `blue-600` = 5.25:1, `gray-900` on `yellow-600` = 6.07:1, `gray-400` on white = 5.43:1, `blue-800` chip on `blue-100` = 7.15:1. All pass WCAG AA.
